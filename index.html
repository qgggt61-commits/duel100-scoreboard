任何人打开本页都能看到最新记录；要记分，需要在本设备粘贴一次访问令牌（管理员生成后发给球友共用）。

管理员如何生成令牌？（只需操作一次）
  1. 登录 GitHub，点右上角头像 → Settings
  2. 左栏最底部 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Token name 随便填（如 duel100）；Expiration 选最长的 1 年
  4. Repository access 选 Only select repositories，勾选 duel100-scoreboard
  5. Permissions → Repository permissions → Contents 改为 Read and write
  6. 点 Generate token，复制 github_pat_ 开头的一长串，粘贴到上面输入框点保存
  7. 把这串令牌发给另外两位球友，各自在自己手机上粘贴一次即可

⚠ 令牌只发给信任的球友——拿到它的人可以修改这个仓库。令牌到期后重新生成一个换上即可。
